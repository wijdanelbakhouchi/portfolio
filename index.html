FLAGSHIP / MASTER’S RESEARCH PROTOTYPE

AgentShield

A Runtime Security Layer for Multi-Agent LLM Systems Against Prompt Injection and Tool Abuse

Autonomous multi-agent architectures introduce expanded attack surfaces: untrusted documents can inject malicious instructions, subagents can abuse privileged tools, and inter-agent communication channels can propagate poisoned context. AgentShield introduces a deterministic runtime mediation layer that inspects handoffs, sandboxes external tools, and enforces fine-grained policy actions across execution boundaries.

ALLOW Safe execution verified
BLOCK Malicious vector intercepted
SANITIZE Instruction markers stripped
REVIEW Human-in-the-loop escalation
